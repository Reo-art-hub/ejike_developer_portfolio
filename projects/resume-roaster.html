Resume Roaster

GPT-4 Next.js PostgreSQL Prisma

An AI-powered resume review platform that helps users improve their CVs with intelligent feedback and competitive ranking.

Project screenshot placeholder

Key contributions

  • Designed and developed the platform end-to-end using Next.js, PostgreSQL, Prisma, and Tailwind CSS
  • Integrated GPT-4 for intelligent resume analysis and actionable feedback
  • Implemented complex SQL queries, including one to identify the top two resumes based on user points
  • Built a responsive UI with accessible forms and clear result presentation
